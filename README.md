# Kunchana Wijesinghe — Software Engineer & Full-Stack Portfolio

Modern, high-performance personal portfolio built with **React 19**, **Tailwind CSS v4**, and **Vite**.

## 🚀 Live Demo & Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🛠️ Tech Stack & Architecture

- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS v4 (Modern Sleek Dark Theme)
- **Typography:** Inter, Plus Jakarta Sans, JetBrains Mono
- **Deployment:** Production static bundle optimized for Vercel / Netlify / GitHub Pages
